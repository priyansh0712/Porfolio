# Plan 10-01: Security Hardening & Rate Limiting Engine

## Phase: Phase 10 - Security Hardening, Verification & Production Readiness
## Plan ID: 10-01
## Objective: Build application rate-limiting decorator/middleware, production security settings (`production.py`), security headers, and full test suite verification.

---

### Key Deliverables:
1. `apps/core/ratelimit.py`:
   - `rate_limit(key='ip', rate='5/m')` cache-backed decorator enforcing request throttling.
2. `config/settings/production.py`:
   - Production settings file loading `SECRET_KEY`, `ALLOWED_HOSTS`, `DATABASE_URL` from environment variables, setting `DEBUG = False`, and enabling production SSL/XSS/HSTS security headers.
3. Decorate Endpoints:
   - Decorate `/login/` with `rate_limit(rate='5/m')`.
   - Decorate `/biometrics/extract/` with `rate_limit(rate='10/m')`.
   - Decorate `/attendance/scan/` with `rate_limit(rate='60/m')`.
4. Unit Tests (`apps/core/tests.py`):
   - Test rate limiter triggers 429 Too Many Requests when request threshold is exceeded.
   - Verify full project test suite execution (100% passing).
