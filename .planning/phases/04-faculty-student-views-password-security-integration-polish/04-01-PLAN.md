# Plan 04-01: Faculty Class & Subject Dashboards

## Phase: Phase 4 - Faculty & Student Views, Password Security & Integration Polish
## Plan ID: 04-01
## Objective: Build "My Class" (`/faculty/my-class/`) and "My Subjects" (`/faculty/my-subjects/`) dashboards for Faculty members with Apple Design System templates and navigation integration.

---

### Key Deliverables:
1. `apps/faculty/views.py`:
   - `MyClassView`: Displays assigned Class Teacher division details, student roster, and quick-add student modal.
   - `MySubjectsView`: Displays Subject Teacher allocations grouped by Subject & Class with read-only student rosters.
2. `apps/faculty/urls.py`:
   - Registered routes `/faculty/my-class/` and `/faculty/my-subjects/`.
3. Templates:
   - `templates/faculty/my_class.html`: Class Teacher dashboard with "+ Add Student" modal.
   - `templates/faculty/my_subjects.html`: Subject Teacher dashboard with subject rosters.
   - `templates/components/navbar_faculty.html`: Update navbar links to include "My Class" and "My Subjects".

---

### Verification:
- Log in as Faculty member assigned as Class Teacher $\to$ verify `/faculty/my-class/` displays assigned division students.
- Log in as Faculty member assigned as Subject Teacher $\to$ verify `/faculty/my-subjects/` displays taught subjects and class rosters.
