    1. Create `apps/accounts/permissions.py`:
       - `SchoolAdminRequiredMixin(AccessMixin)` & `@school_admin_required`:
         - Verify `request.user.is_authenticated`.
         - Verify `request.user.role == User.Role.SCHOOL_ADMIN`.
         - Verify `request.user.school == request.tenant`.
         - If check fails: return `HttpResponseForbidden("Access denied: School Admin authorization required.")` or redirect to login.
       - `SuperAdminRequiredMixin(AccessMixin)` & `@super_admin_required`:
         - Verify `request.user.is_authenticated`.
         - Verify `request.user.role == User.Role.SUPER_ADMIN`.
         - Verify `request.tenant is None` (must be on root domain).
         - If check fails: return `HttpResponseForbidden("Access denied: Super Admin authorization required.")`.
    2. Create `apps/accounts/middleware.py`:
       - Define `TenantRoleAccessMiddleware`:
         - Inspect `request.path` and `request.user`.
         - If `request.user.is_authenticated` and `request.user.role == User.Role.SUPER_ADMIN`:
           - If `request.path` starts with tenant-scoped prefixes (`/faculty/`, `/biometrics/`, `/attendance/`, `/reports/`):
             Return `HttpResponseForbidden("Super Admin is strictly prohibited from accessing tenant faculty and biometric records (AUTH-02).")`.
         - If `request.user.is_authenticated` and `request.user.role in (User.Role.SCHOOL_ADMIN, User.Role.FACULTY)`:
           - If `request.path` starts with `/superadmin/`:
             Return `HttpResponseForbidden("Access denied: Platform management is restricted to Super Admin.")`.
    3. Add `'apps.accounts.middleware.TenantRoleAccessMiddleware'` to `MIDDLEWARE` in `config/settings/base.py` right after `TenantMiddleware`.
  </action>

    - TenantRoleAccessMiddleware blocks Super Admin from tenant routes (/faculty/, /attendance/, etc.) with HTTP 403

  </acceptance_criteria>
