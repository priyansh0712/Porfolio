## Shipped Requirements

### Leave Management & Allocation
- [x] **LEAVE-ALLOC**: School Admin can upload an Excel file to assign/update leave allocations for existing faculty, with validation.
- [x] **LEAVE-BAL**: Track Allocated, Used, and Remaining leave balances per faculty (Casual, Sick, Paid) with dynamic balance computation.
- [x] **LEAVE-REQ**: Faculty members can apply for leave via form with validation (date ordering, overlap checks, balance checks).
- [x] **LEAVE-APP**: School Admin can review, filter, approve, or reject leave requests (rejection requires mandatory non-empty explanation).
- [x] **LEAVE-OVERLAP**: System rejects overlapping leave requests for same faculty.
- [x] **LEAVE-HOL**: Respects school working schedules and holidays in leave calculations (non-working days do not deduct balance).

### Faculty Dashboard & Attendance
- [x] **FAC-DASH**: Faculty personal dashboard displaying today's attendance, summary stats, leave balances, pending requests, and notifications.
- [x] **MY-ATT**: Faculty "My Attendance" page showing summary metrics and date-wise log history.
- [x] **LEAVE-INT**: Approved leaves automatically create attendance log records with status `LEAVE` and null check-in times.

### Notifications & Security
- [x] **LEAVE-NOTIF**: Real-time in-app notifications on submission, approval, and rejection with unread navbar badge.
- [x] **SEC-V2**: Strict role-based permissions (School Admin vs Faculty vs Super Admin) and multi-tenant isolation across all V2 features.
