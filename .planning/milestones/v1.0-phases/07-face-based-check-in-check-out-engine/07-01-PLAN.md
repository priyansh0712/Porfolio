# Plan 07-01: Kiosk UI, Real-time Camera Scanner & Audio Feedback

## Phase: Phase 7 - Face-Based Check-In & Check-Out Engine
## Plan ID: 07-01
## Objective: Deliver dedicated fullscreen kiosk scanning UI (`/attendance/kiosk/`), Vanilla JS continuous frame capture loop (~500ms), Web Audio chime synthesis ($E_5 \to B_5$), Screen Wake Lock API integration, and instant visual status badges.

---

### Key Deliverables:
1. `apps/attendance/views.py`: `AttendanceKioskView` rendering fullscreen kiosk interface.
2. `apps/attendance/urls.py`: URL pattern mapping `/attendance/kiosk/` to `AttendanceKioskView`.
3. `templates/attendance/kiosk.html`: Fullscreen Apple-aesthetic Kiosk template with live clock widget, tenant logo badge, camera stream viewport, and overlay status cards.
4. `static/js/attendance_scanner.js`: Modular JS scanner handling:
   - `navigator.mediaDevices.getUserMedia` camera stream initialization & auto-reconnect handling.
   - Screen Wake Lock API (`navigator.wakeLock.request('screen')`) preventing display sleep during school hours.
   - Canvas hidden frame extraction (~500ms sampling frequency).
   - Local 30-second per-faculty scan cooldown memory cache (`Map<faculty_id, timestamp>`).
   - Web Audio API synthesizer generating dual-tone chord chime ($E_5 \to B_5$, 659.25Hz $\to$ 987.77Hz) for success and low pulse ($D_3$, 146.83Hz) for warning.
   - 3-second automatic UI status badge reset timer.

---

### Verification:
- Open `/attendance/kiosk/` on tenant subdomain (`schoola.localhost:8000`).
- Verify camera stream initializes cleanly with overlay clock and status badges.
- Verify audio chime triggers on recognition event simulation.
