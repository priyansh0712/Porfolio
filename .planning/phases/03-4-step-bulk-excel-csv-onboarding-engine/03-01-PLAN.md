# Plan 03-01: Bulk Import Validation Engine, Sample Generators & Services

## Phase: Phase 3 - 4-Step Bulk Excel/CSV Onboarding Engine
## Plan ID: 03-01
## Objective: Build `apps/onboarding/services.py` with openpyxl/csv parsers, validation preview engine for all 4 steps, atomic commit service, and downloadable sample file generator.

---

### Key Deliverables:
1. `apps/onboarding/services.py`:
   - `SampleTemplateService`: Generates `.xlsx` (using `openpyxl`) and `.csv` sample files for Steps 1, 2, 3, and 4 with headers and instructions.
   - `BulkImportParser`: Parses uploaded `.xlsx` and `.csv` files into list of dictionaries.
   - `BulkValidationService`:
     - `validate_step_1_faculty(school, rows)`
     - `validate_step_2_classes(school, rows)`
     - `validate_step_3_subjects(school, rows)`
     - `validate_step_4_students(school, rows)`
     - Returns list of row dicts with `row_index`, `data`, `status` (`VALID`/`ERROR`), and `errors` list.
   - `BulkCommitService`:
     - `@transaction.atomic` commit methods for all 4 steps executing model creation and default user account generation (`password='Admin@123'`).

---

### Verification:
- Unit test suite verifying sample file generation, parser error handling, validation checks (duplicate GR numbers, missing standards, invalid emails), and atomic commits.
