    1. Create `apps/accounts/auth_backends.py`:
       - Define `TenantAwareAuthBackend(ModelBackend)`:
         - Override `authenticate(request, username=None, password=None, **kwargs)`:
           - Retrieve email from `username` or `kwargs.get('email')`.
           - Fetch user by `email`. Check `user.check_password(password)`.
           - Verification logic:
             - If `request` has `request.tenant` set (tenant subdomain):
               - If `user.role == Role.SUPER_ADMIN`: return `None` (Super Admin cannot log in on school subdomain).
               - If `user.school != request.tenant`: return `None` (Cross-tenant login attempt rejected).
             - If `request` has `request.tenant is None` (root domain):
               - If `user.role != Role.SUPER_ADMIN`: return `None` (Tenant users cannot log in on root domain login).
           - Return `user` if valid, else `None`.
    2. Register `AUTHENTICATION_BACKENDS = ['apps.accounts.auth_backends.TenantAwareAuthBackend', 'django.contrib.auth.backends.ModelBackend']` in `config/settings/base.py`.
    3. Create `apps/accounts/forms.py`:
       - `TenantLoginForm(AuthenticationForm)` using `email` field instead of username.
    4. Create `apps/accounts/views.py`:
       - `TenantLoginView(LoginView)`: uses `TenantLoginForm`, template `accounts/login.html`. Redirects School Admin to `/dashboard/` and Super Admin to `/superadmin/`.
       - `TenantLogoutView(LogoutView)`: logs out user and redirects to `/login/`.
       - `TenantDashboardView(TemplateView)`: renders `accounts/dashboard.html` for logged-in tenant users.
    5. Create `apps/accounts/urls.py` (`/login/`, `/logout/`, `/dashboard/`) and include in `config/urls.py`.
