# Plan 03-02: Stepper Wizard Views, Validation Preview Table & UI Suite

## Phase: Phase 3 - 4-Step Bulk Excel/CSV Onboarding Engine
## Plan ID: 03-02
## Objective: Build `apps/onboarding/views.py`, URL routes, Apple-style Stepper Wizard UI (`onboarding_wizard.html`), sample download endpoints, and end-to-end unit test suite.

---

### Key Deliverables:
1. `apps/onboarding/views.py`:
   - `OnboardingWizardView` (`/onboarding/wizard/`): Renders 4-step wizard interface.
   - `OnboardingValidateAPIView` (`/onboarding/api/validate/`): AJAX endpoint parsing file and returning validation preview JSON.
   - `OnboardingCommitAPIView` (`/onboarding/api/commit/`): AJAX endpoint executing atomic database commit.
   - `SampleTemplateDownloadView` (`/onboarding/sample/<step>/<fmt>/`): Streams downloadable sample templates.
2. `apps/onboarding/urls.py` & `config/urls.py`:
   - Registered routes under `/onboarding/`.
3. `templates/onboarding/wizard.html`:
   - Apple Design System 4-step progress header, file upload dropzone, sample download buttons, interactive validation preview drawer, and commitment confirmation modal.
4. Unit Test Suite (`apps/onboarding/tests.py`):
   - Tests for sample downloads, file uploads, row-by-row validation, duplicate GR number rejection, and successful multi-step commits.
