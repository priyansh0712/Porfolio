# Plan 05-01: Faculty & TenantSequence Models, Auto-Code Generator, Forms, and Service Layer

## Objective
Establish the `apps.faculty` Django application containing the `Faculty` and `TenantSequence` models, the race-condition-safe `FacultyCodeService` using PostgreSQL `select_for_update()` row locking, `FacultyForm` with tenant-scoped validation, and the backend service layer handling linked `User` account creation (`role=FACULTY`, `set_unusable_password()`, `on_delete=SET_NULL`).

## Tasks

### Task 1: Create `apps.faculty` Django App & Register in Settings
- Create app directory `apps/faculty/` with standard `__init__.py`, `apps.py`, `models.py`, `forms.py`, `services.py`, `admin.py`.
- Register `'apps.faculty'` in `INSTALLED_APPS` in `config/settings/base.py`.

### Task 2: Define Models in `apps/faculty/models.py`
- Define `TenantSequence(TenantModel)`:
  - `sequence_type = CharField(max_length=50, default='FACULTY')`
  - `last_value = PositiveIntegerField(default=0)`
  - `UniqueConstraint(fields=['school', 'sequence_type'], name='unique_tenant_sequence_type')`
- Define `Faculty(TenantModel)`:
  - `user = OneToOneField(User, on_delete=models.SET_NULL, null=True, blank=True, related_name='faculty_profile')`
  - `first_name = CharField(max_length=150)`
  - `last_name = CharField(max_length=150)`
  - `email = EmailField(unique=True)` (Globally unique to match `User.email`)
  - `phone_number = CharField(max_length=20, blank=True)`
  - `employee_code = CharField(max_length=50, db_index=True)`
  - `department = CharField(max_length=100)`
  - `designation = CharField(max_length=100)`
  - `date_joined = DateField(auto_now_add=True)`
  - `is_active = BooleanField(default=True)`
  - `is_face_enrolled = BooleanField(default=False, help_text="Architecture hook for Phase 6 vector status")`
  - Meta constraints: `UniqueConstraint(fields=['school', 'employee_code'], name='unique_faculty_code_per_school')`
  - `@property` `full_name`: returns `f"{self.first_name} {self.last_name}"`

### Task 3: Create `FacultyCodeService` & `FacultyService` in `apps/faculty/services.py`
- `FacultyCodeService.generate_next_code(school)`:
  - Uses `@transaction.atomic` and `TenantSequence.objects.select_for_update().get_or_create(school=school, sequence_type='FACULTY')`.
  - Increments `last_value`, saves, and returns `f"{school.subdomain.upper()}-FAC-{last_value:03d}"`.
- `FacultyService.create_faculty(school, data)`:
  - Auto-generates `employee_code` if not provided in `data`.
  - Creates linked `User(username=email, email=email, first_name=first_name, last_name=last_name, role=User.Role.FACULTY, school=school)`.
  - Calls `user.set_unusable_password()` and `user.save()`.
  - Creates and returns `Faculty` record linked to `user` and `school`.
- `FacultyService.update_faculty(faculty, data)`:
  - Updates fields and synchronizes `first_name`, `last_name`, `email` with linked `User`.
- `FacultyService.toggle_status(faculty)`:
  - Inverts `faculty.is_active` and synchronizes `user.is_active = faculty.is_active` if `user` exists.

### Task 4: Create `FacultyForm` in `apps/faculty/forms.py`
- ModelForm for `Faculty` fields: `first_name`, `last_name`, `email`, `phone_number`, `employee_code`, `department`, `designation`.
- `employee_code` field is `required=False` (triggers auto-generation if left blank).
- `clean_email()`: Checks `User.objects.filter(email__iexact=email)` to reject already-registered emails globally.
- `clean_employee_code()`: Checks `Faculty.objects.filter(school=self.tenant, employee_code__iexact=code)` to enforce per-school uniqueness.

### Task 5: Register Admin & Make Migrations
- Register `Faculty` and `TenantSequence` in `apps/faculty/admin.py`.
- Run `python manage.py makemigrations` and `python manage.py migrate`.

- `python manage.py migrate` applies migrations cleanly without errors.
