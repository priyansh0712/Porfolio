# Plan 09-01: School Admin Dashboard & Attendance Reporting Suite

## Phase: Phase 9 - Admin Dashboard, Reports & Audit Log
## Plan ID: 09-01
## Objective: Build School Admin Dashboard (`/dashboard/`), Date-wise & Faculty-wise Attendance Reports page (`/reports/`), and CSV Exporter (`/reports/export/csv/`).

---

### Key Deliverables:
1. `apps/reports/services.py`:
   - `DashboardService.get_metrics(school)` computing total faculty, present today, late today, half-day today, absent today, and today's live feed.
   - `ReportService.get_report_data(school, start_date, end_date, department, status)` query engine.
   - `ReportService.generate_csv(school, queryset)` generating CSV output.
2. `apps/reports/views.py`:
   - `AdminDashboardView` (`/dashboard/`) extending `SchoolAdminRequiredMixin`.
   - `AttendanceReportView` (`/reports/`) extending `SchoolAdminRequiredMixin`.
   - `AttendanceExportCSVView` (`/reports/export/csv/`) extending `SchoolAdminRequiredMixin`.
3. `templates/reports/dashboard.html`:
   - Apple Design System 5-card KPI summary header + Live Activity feed table.
4. `templates/reports/attendance_report.html`:
   - Date range picker, department dropdown, status filter, and CSV Export download button.

---

### Verification:
- Access `/dashboard/` as School Admin and verify KPI cards & today's activity feed.
- Access `/reports/` and filter by date range and department.
- Click "Export CSV" and verify downloaded `.csv` file format.
