# Plan 06-01: Biometrics App, FacultyBiometric Model, InsightFace Pipeline, and Service Layer

## Objective
Establish the `apps.biometrics` Django application, define the `FacultyBiometric` model storing normalized 512-d ArcFace vector embeddings in PostgreSQL `JSONB`, implement the `BiometricService` layer handling in-memory base64 frame decoding, strict `len(frames) == 3` payload validation, single-face & bounding-box quality checks, element-wise embedding averaging, L2 unit normalization, instant RAM photo byte destruction, and atomic DB enrollment.

## Tasks

### Task 1: Create `apps.biometrics` Django App & Register in Settings
- Create app directory `apps/biometrics/` with `__init__.py`, `apps.py`, `models.py`, `services.py`, `admin.py`.
- Register `'apps.biometrics'` in `INSTALLED_APPS` in `config/settings/base.py`.

### Task 2: Define `FacultyBiometric` Model in `apps/biometrics/models.py`
- Inherit from `TenantModel` (includes `school` ForeignKey).
- Fields:
  - `faculty = OneToOneField(Faculty, on_delete=models.CASCADE, related_name='biometric')`
  - `embedding = JSONField(help_text="512-dimensional normalized ArcFace float embedding vector")`
  - `enrolled_at = DateTimeField(auto_now=True)`
  - `enrolled_by = ForeignKey(User, null=True, blank=True, on_delete=models.SET_NULL, related_name='enrolled_biometrics')`
- Meta:
  - `verbose_name = 'Faculty Biometric'`
  - `verbose_name_plural = 'Faculty Biometrics'`

### Task 3: Create `BiometricService` in `apps/biometrics/services.py`
- **InsightFace Singleton**:
  - `get_face_analyzer()`: Lazy process-level singleton initializing `FaceAnalysis(name='buffalo_l', providers=['CPUExecutionProvider'])`.
- **In-Memory Frame Decoder**:
  - `decode_base64_frame(base64_str)`: Decodes base64 string directly into NumPy BGR matrix via `cv2.imdecode`. Immediately calls `del img_bytes, nparr` to destroy raw payload from RAM.
- **Enrollment Handler**:
  - `enroll_faculty_face(school, faculty, base64_frames, user=None)`:
    - **Strict Validation**: Require `len(base64_frames) == 3`. Raise `ValueError` if frame count != 3.
    - Validate total payload size (max 5MB limit).
    - Loop through 3 frames: decode in RAM, call `analyzer.get(img)`.
    - Quality checks per frame:
      - `len(faces) == 0`: Raise `ValueError("Frame X: No face detected.")`
      - `len(faces) > 1`: Raise `ValueError("Frame X: Multiple faces detected.")`
      - Face size: Bounding box width/height must be `>= 120` px.
      - Instantly destroy frame matrix: `del img; gc.collect()`.
    - Multi-frame math: Compute element-wise mean `avg_emb = np.mean(embeddings, axis=0)`, compute L2 norm `norm = np.linalg.norm(avg_emb)`, and normalize `(avg_emb / norm).tolist()`.
    - Save/update `FacultyBiometric` inside `@transaction.atomic`.
    - Set `faculty.is_face_enrolled = True` and save.
- **Reset Handler**:
  - `reset_faculty_face(school, faculty)`:
    - Inside `@transaction.atomic`: Deletes `FacultyBiometric` if exists, sets `faculty.is_face_enrolled = False`, saves `faculty`.

### Task 4: Register Admin & Make Migrations
- Register `FacultyBiometric` in `apps/biometrics/admin.py`.
- Run `python manage.py makemigrations biometrics` and `python manage.py migrate`.
