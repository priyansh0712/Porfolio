    Create `apps/academics/models.py` defining 6 models inheriting `TenantModel`:
    1. `AcademicYear`:
       - `name`: `CharField(max_length=50)` (e.g. "2026-2027")
       - `start_date`: `DateField()`
       - `end_date`: `DateField()`
       - `is_current`: `BooleanField(default=False)`
       - Constraint: `UniqueConstraint(fields=['school', 'name'], name='unique_academic_year_name_per_school')`
       - Ordering: `['-start_date']`
       - `clean()`: validate `start_date < end_date`.
       - `@transaction.atomic def save(self, *args, **kwargs)`: if `self.is_current`, deactivate other academic years for `self.school` using `.exclude(pk=self.pk).update(is_current=False)`.
    2. `Standard`:
       - `name`: `CharField(max_length=50)` (e.g. "Standard 10", "UKG")
       - `order_index`: `PositiveIntegerField(default=0)` for sorting
       - `is_active`: `BooleanField(default=True)`
       - Constraint: `UniqueConstraint(fields=['school', 'name'], name='unique_standard_name_per_school')`
       - Ordering: `['order_index', 'name']`
    3. `Division`:
       - `standard`: `ForeignKey('academics.Standard', on_delete=models.PROTECT, related_name='divisions')`
       - `name`: `CharField(max_length=20)` (e.g. "A", "B", "Rose")
       - `is_active`: `BooleanField(default=True)`
       - Constraint: `UniqueConstraint(fields=['school', 'standard', 'name'], name='unique_division_per_standard_per_school')`
       - Ordering: `['standard__order_index', 'name']`
       - `__str__`: `f"{self.standard.name} - {self.name}"`
    4. `Subject`:
       - `SubjectType` TextChoices: `CORE = 'CORE', 'Core Subject'`, `ELECTIVE = 'ELECTIVE', 'Elective / Optional'`
       - `name`: `CharField(max_length=100)`
       - `code`: `CharField(max_length=30)` (auto-uppercased in `clean()`)
       - `subject_type`: `CharField(max_length=20, choices=SubjectType.choices, default=SubjectType.CORE)`
       - `is_active`: `BooleanField(default=True)`
       - Constraint: `UniqueConstraint(fields=['school', 'code'], name='unique_subject_code_per_school')`
       - Ordering: `['name']`
    5. `ClassTeacherAllocation`:
       - `academic_year`: `ForeignKey(AcademicYear, on_delete=models.CASCADE, related_name='class_teacher_allocations')`
       - `division`: `ForeignKey(Division, on_delete=models.PROTECT, related_name='class_teacher_allocations')`
       - `faculty`: `ForeignKey('faculty.Faculty', on_delete=models.PROTECT, related_name='class_teacher_allocations')`
       - Constraint: `UniqueConstraint(fields=['school', 'academic_year', 'division'], name='unique_class_teacher_per_division_year')`
       - `clean()`: validate `faculty.school_id == self.school_id` and `faculty.is_active is True`.
    6. `SubjectTeacherAllocation`:
       - `academic_year`: `ForeignKey(AcademicYear, on_delete=models.CASCADE, related_name='subject_teacher_allocations')`
       - `division`: `ForeignKey(Division, on_delete=models.PROTECT, related_name='subject_teacher_allocations')`
       - `subject`: `ForeignKey(Subject, on_delete=models.PROTECT, related_name='subject_teacher_allocations')`
       - `faculty`: `ForeignKey('faculty.Faculty', on_delete=models.PROTECT, related_name='subject_teacher_allocations')`
       - Constraint: `UniqueConstraint(fields=['school', 'academic_year', 'division', 'subject'], name='unique_subject_teacher_per_division_subject_year')`
       - `clean()`: validate `faculty.school_id == self.school_id` and `faculty.is_active is True`.
