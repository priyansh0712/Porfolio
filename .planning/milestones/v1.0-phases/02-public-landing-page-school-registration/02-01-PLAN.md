# Plan 02-01: Public Landing Page View & Templates

## Phase: Phase 2 - Public Landing Page & School Registration
## Plan ID: 02-01
## Objective: Create the public marketing landing page (`ourapp.com`) showcasing product benefits, face recognition highlights, security positioning, pricing structure, FAQ, and "Register Your School" CTA.

---

### Key Deliverables:
1. `apps/public/views.py`: `LandingPageView` rendering public marketing page.
2. `apps/public/urls.py`: URL patterns mapping `/` to `LandingPageView`.
3. `config/urls.py`: Include `apps.public.urls` for root domain traffic.
4. `templates/public/landing.html`: Responsive, high-converting Tailwind landing page template with hero, feature grids, biometric security highlights, pricing tiers, FAQ accordion, and CTA header/footer.

### Implementation Details:
- **Hero Section**: Value proposition ("Webcam-based Faculty Face Attendance for Modern Schools"), CTA button to `/register/`, dynamic preview mockups.
- **Features Grid**: Real-time webcam check-in/out, multi-tenant isolation, automated punctuality rules, admin dashboard & reporting.
- **Security & Privacy Focus**: Emphasize zero-raw-photo storage policy (512-d ArcFace vector embeddings processed purely in-memory).
- **Pricing Section**: Clear school pricing tiers (Basic, Standard, Enterprise).
- **FAQ Section**: Interactive HTML details/summary accordion addressing school admin questions.
- **CTA Sections**: Prominent header and bottom banner directing school admins to registration flow.

---

- Verify all landing page sections render correctly with clean Tailwind styles and responsive mobile/desktop layouts.
