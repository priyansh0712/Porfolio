# Plan 07-02: Biometric Face Vector Identification & Matching Service

## Phase: Phase 7 - Face-Based Check-In & Check-Out Engine
## Plan ID: 07-02
## Objective: Build high-performance face vector identification engine matching incoming webcam face embeddings against active tenant faculty biometric vectors using L2 Cosine Distance matrix multiplication ($\le 0.40$ threshold).

---

### Key Deliverables:
1. `apps/attendance/services.py`: `FaceVectorMatcher` service implementing:
   - In-memory retrieval of active tenant `FacultyBiometric` vector embeddings (`request.tenant`).
   - Efficient NumPy dot product matrix multiplication ($V_{scan} \cdot V_{tenant}^T$) evaluating Cosine Distance ($1.0 - \text{similarity}$).
   - Match threshold validation (Cosine Distance $\le 0.40$, corresponding to Cosine Similarity $\ge 0.60$).
   - Returns matched `Faculty` model instance and score or `None` if unrecognized.
2. `apps/attendance/views.py`: `AttendanceScanAPIView` endpoint (`POST /attendance/api/scan/`):
   - Accepts `{ "vector": [512 floats] }` JSON payload.
   - Strictly validates active tenant subdomain context from `TenantMiddleware`.
   - Delegates vector to `FaceVectorMatcher` and forwards result to attendance state machine.

---

### Verification:
- Unit test matching engine against known vector arrays (matching vector returns correct faculty; random vector returns None).
- Verify tenant isolation (scanning vector enrolled under School A returns `None` under School B).
