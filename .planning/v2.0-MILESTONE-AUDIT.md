## 3. Integration & System Architecture Audit

1. **Leaves ↔ Attendance Engine Integration**: Approved leave requests trigger transaction-atomic creation of `AttendanceLog` records with status `LEAVE` and nullable `check_in_time`. Reports and Admin KPI counters accurately process `LEAVE` status.
2. **Leaves ↔ Working Schedule Engine Integration**: Leave request length calculations bypass configured non-working days (e.g., Sundays) and custom school holidays without deducting faculty balance.
3. **Leaves ↔ In-App Notification System**: Context processors inject unread notification badges dynamically across the responsive navbar layout for faculty and admins.
4. **Security & Data Isolation**: `TenantMiddleware` and `TenantModel` scoping prevent cross-tenant parameter tampering across all leave requests, allocations, and history views.
