# Plan 06-02: Face Enrollment Views, Web Cam Modal UI, Profile Integration, and Automated Test Suite

## Objective
Deliver tenant-scoped biometric AJAX views (`FacultyFaceEnrollView` & `FacultyFaceResetView`) protected by 3-layer security mixins and strict `application/json` payload parsing, construct the Apple Frosted Glass Face Enrollment Modal Drawer with browser `getUserMedia` camera feed and real-time bounding box guide, integrate enrollment triggers into the Faculty Profile Drawer, and construct a comprehensive automated test suite (`tests_biometrics.py`).

## Tasks

### Task 1: Create Tenant-Scoped Biometric Views in `apps/biometrics/views.py`
- `FacultyFaceEnrollView(SchoolAdminRequiredMixin, View)`:
  - POST-only AJAX endpoint for `/faculty/<int:pk>/enroll-face/`.
  - Enforces 3-layer security: matches `school = request.tenant` and `pk = faculty_id`.
  - Parses JSON payload (`request.body`). Validates `Content-Type == application/json`.
  - Enforces payload size limit (max 5MB).
  - Calls `BiometricService.enroll_faculty_face(request.tenant, faculty, frames, request.user)`.
  - Returns `JsonResponse({'success': True, 'message': '...'})` on success, or `JsonResponse({'success': False, 'error': str(e)}, status=400)` on validation failure.
- `FacultyFaceResetView(SchoolAdminRequiredMixin, View)`:
  - POST-only AJAX endpoint for `/faculty/<int:pk>/reset-face/`.
  - Calls `BiometricService.reset_faculty_face(request.tenant, faculty)`.
  - Returns JSON success status.

### Task 2: Configure URL Routing in `apps/biometrics/urls.py` & `config/urls.py`
- Create `apps/biometrics/urls.py`:
  - `path('<int:pk>/enroll-face/', views.FacultyFaceEnrollView.as_view(), name='enroll_face')`
  - `path('<int:pk>/reset-face/', views.FacultyFaceResetView.as_view(), name='reset_face')`
- Include `apps.biometrics.urls` in `config/urls.py` under `'faculty/'` path or `'biometrics/'` namespace.

### Task 3: Build Web Cam Enrollment Modal UI & Profile Integration
- `templates/faculty/includes/enroll_face_modal.html`:
  - Apple Frosted Glass Modal Drawer (`#enroll-face-modal`).
  - Container for `<video id="enroll-video" autoplay playsinline muted></video>` with canvas guide overlay.
  - Interactive status banner (e.g. "Center your face inside the frame").
  - JavaScript 3-frame 300ms sampler function `captureAndEnrollFace(facultyId)`.
  - Transmits payload using `Content-Type: application/json` and `X-CSRFToken`.
- Update `templates/faculty/faculty_list.html`:
  - Include `enroll_face_modal.html`.
  - In Faculty Profile Drawer (`#profile-modal-drawer`), add **`📷 Enroll Face ID`** button when `is_face_enrolled == False` and **`🔄 Re-enroll Face`** / **`❌ Reset Face ID`** buttons when `is_face_enrolled == True`.

### Task 4: Build Automated Test Suite in `apps/biometrics/tests_biometrics.py`
- Test 1: **Tenant Query & Enrollment Scoping** — School A admin cannot enroll face for School B faculty ID (returns HTTP 404/403).
- Test 2: **Strict 3-Frame Validation** — Sending 1 frame or 4 frames to `BiometricService.enroll_faculty_face()` raises `ValueError` and rejects request.
- Test 3: **Content-Type & Payload Validation** — POST request without `application/json` or invalid JSON body returns HTTP 400.
- Test 4: **Biometric Model & CASCADE Delete** — Creating `FacultyBiometric` updates `faculty.is_face_enrolled = True`. Deleting `Faculty` cascades and deletes `FacultyBiometric`.
- Test 5: **Reset Biometrics** — Calling `FacultyFaceResetView` deletes `FacultyBiometric` and resets `faculty.is_face_enrolled = False`.
- Test 6: **Vector Normalization** — Verify saved embedding vector is a list of 512 floats with L2 magnitude equal to 1.0 (`np.linalg.norm(vec) == 1.0`).

## Verification Criteria
- All 6 tests in `python manage.py test apps.biometrics.tests_biometrics --settings=config.settings.local` pass 100%.
- System check `python manage.py check --settings=config.settings.local` reports 0 errors.
- Visual/manual test on `http://greenwood.localhost:8000/faculty/` confirms camera modal drawer opens and renders video feed cleanly.
